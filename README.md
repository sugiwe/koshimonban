# 腰門番（こしもんばん）

座りっぱなしを防ぐための macOS メニューバーアプリです。
決まった時刻に画面を全画面で覆って、立ち上がってストレッチするよう促します。

作者が座りっぱなしのデスクワークで腰を痛めたことがきっかけで作りました。
30分に1回立ち上がるのが理想ですが、意志だけでは続きませんでした。

このアプリで大事にしているのは、機能の豊かさではなく「無視されにくさ」です。
設計上の判断は、すべて次の優先順位で決めています。

1. 発動が確実であること（作業時間帯なら、何があっても画面が出る）
2. 逃げ道はあるが、摩擦があること（スキップは押せるが、無自覚には押せない）
3. サボった事実が残ること
4. 見た目や機能の豊かさ（最下位）

なぜそう決めたのかは [SPEC.md](SPEC.md) に書いてあります。

## どう動くか

- 設定した作業時間帯の中で、決まった間隔（既定 30分）ごとに発動します
- 発動すると全ディスプレイが全画面で覆われます。他アプリのネイティブフルスクリーンの上にも出ます
- 3・2・1 のあと、登録しておいたストレッチ動画（YouTube またはローカルファイル）が再生されます
- 既定は3分間です。「腰を守った✌️」で切り上げられます
- 「腰より仕事💀」でスキップできますが、最初の5秒間は押せません。押すと理由を1つ選ぶことになります
- `Esc` では閉じません（意図的にそうしてあります）
- 完了・短縮・スキップ・取りこぼしが記録され、達成率とヒートマップで見返せます

## 逃げ道

画面を奪うアプリですので、先に抜け方を書いておきます。

| 状況 | 対処 |
| --- | --- |
| 今は発動してほしくない | メニューバーから「30分停止」「1時間停止」「今日はもう停止」 |
| オーバーレイから抜けたい | 「腰を守った✌️」または「腰より仕事💀」。カウントダウンが0になれば必ず閉じます |
| アプリごと止めたい | メニューバーから「腰門番を終了」、または `pkill -x Koshimonban` |
| 自動起動をやめたい | 設定 →「一般」→「ログイン時に自動起動」をオフ |

## 動作環境

- macOS 14 以上
- ビルドには Xcode 16 以上（開発は Xcode 26 / macOS 26 で行っています）

外部ライブラリへの依存はありません。標準フレームワークのみで動きます。

## 使ってみる

配布用のビルド済みアプリは用意していないため、ご自身でビルドしていただく必要があります。

```bash
git clone https://github.com/sugiwe/koshimonban.git
cd koshimonban
./tools/deploy.sh
```

`deploy.sh` が、ビルド → `/Applications/Koshimonban.app` へ配置 → 起動までを行います。
Dock にはアイコンが出ません（`LSUIElement` のためです）。メニューバー右上の人型アイコンから操作します。

Xcode を入れた直後は、先に次が必要になることがあります。

```bash
sudo xcodebuild -license accept
sudo xcodebuild -runFirstLaunch
```

より詳しい手順は [docs/SETUP.md](docs/SETUP.md) にあります。

### 最初にやる設定

メニューバーのアイコン →「設定を開く」から進めます。

1. **「作業時間帯」タブ** — 実際の勤務時間に合わせてください（既定は月〜金の 10:00–12:00 と 14:00–17:00 です）。
   下部の「今日の発動予定」に実際の発動時刻が並ぶので、意図どおりか確認できます
2. **「動画」タブ** — ストレッチ動画を登録します。0件でも動きます（テキストとカウントダウンだけになります）。
   複数登録すると発動ごとに切り替わり、前回と同じものは続けて出ません
3. **「一般」タブ** — 間隔・休憩の長さ・予告の秒数・自動起動

### コードを直したとき

```bash
git pull
./tools/deploy.sh
```

アプリの置き場所は変わらないので、自動起動の登録をやり直す必要はありません。

## 発動時刻の決まり方

各作業時間帯の開始時刻を起点とした、固定のグリッドで決めています。

```
10:00–12:00 / 間隔30分 → 10:30, 11:00, 11:30
```

- 時間帯の終端（12:00）では発動しません
- 休憩が時間帯からはみ出す発動もしません（3分休憩なら 11:58 には発動しません）
- スキップしてもグリッドはズレません。体がリズムを覚えられるようにするためです

スリープや画面ロックで発動時刻を過ぎた場合、休憩が時間帯に収まるうちは追いつきます。
間に合わなければ「取りこぼし」として記録に残ります。

## 自動起動

ログイン時の自動起動は `SMAppService` ではなく LaunchAgent で行っています
（`~/Library/LaunchAgents/net.sugiwe.koshimonban.plist`）。設定の「一般」タブから登録できます。

`SMAppService` を使っていないのは、正しいコード署名を要求するためです。
Apple Developer Program に加入していないローカルビルドでは、無料 Apple ID の証明書が
7日で失効してアプリが起動しなくなります。毎週ビルドし直す運用は、
「意志に頼らない」というこのアプリの前提と正面から衝突します。

`KeepAlive` に `SuccessfulExit: false` を指定してあるため、
異常終了したときは自動で復帰しますが、メニューの「終了」で終わらせた場合は復帰しません。
逃げ道を塞がないための設定です。

登録した plist には、アプリの実行ファイルのパスが埋め込まれます。
`deploy.sh` が `/Applications` に置くのはこのためです。
パスが食い違っている場合は設定画面に警告が出ます。

## データの保存先

```
~/Library/Application Support/Koshimonban/
  settings.json        設定
  logs/YYYY-MM.json    記録
```

JSON なので直接開いて編集できます。読めない状態になっていた場合は
`.corrupt-日時` にリネームして退避し、既定値で起動します（削除はしません）。

このデータはマシンごとにローカル保存されます。複数の Mac で使うと記録が分裂し、
達成率やヒートマップがそれぞれの Mac の分しか映りません。同期は対象外です。
主に作業する Mac 1台だけで使うのが素直だと思います。

## Xcode のない Mac に持ち込む

ビルド済みの `Koshimonban.app` をコピーすれば動きます。
ad-hoc 署名は特定のマシンに紐づかないため、そのまま起動できます。

ただし AirDrop やダウンロード経由で転送すると Gatekeeper に隔離属性を付けられ、
「開発元を確認できないため開けません」と表示されます。その場合は次のいずれかで通せます。

- `.app` を右クリック →「開く」→ ダイアログで「開く」
- システム設定 →「プライバシーとセキュリティ」→「このまま開く」
- `xattr -d com.apple.quarantine /path/to/Koshimonban.app`

`scp` や USB メモリ経由なら隔離属性が付かないことが多く、そのまま起動できます。

## 開発

### tests/

発動判定と URL 解析の検証です。Xcode は不要で、`swiftc` だけで走ります。

```bash
./tests/run.sh
```

このアプリは実時間で動くため、境界条件をアプリ上で確かめると1回30分かかります。
副作用のない計算部分を切り出して、ここで一気に確認しています。

### tools/

```bash
./tools/deploy.sh      # ビルド → /Applications に配置 → 起動
./tools/make-icon.sh   # tools/icon-source.png から AppIcon.icns を生成
```

アイコンの絵を変えたいときは、`tools/icon-source.png` を差し替えて `make-icon.sh` を実行します。
元画像は正方形・中央配置であれば大丈夫です。macOS は iOS と違ってアイコンの角丸を
自動でマスクしてくれないため、スクリプト側で絵の本体を切り出し、squircle に収めて
外側を透明にしています。角丸の外が黒く塗られた画像でも、そのまま渡して問題ありません。

### spike/

最前面表示とフォーカス奪取が本当に成立するかを確かめた、使い捨ての検証アプリです。
オーバーレイの実装で迷ったときの参照用に残してあります。
詳細は [spike/README.md](spike/README.md) をご覧ください。

### デバッグモード

実時間で待たずに動作を確認したいときに使います。設定 →「開発」タブから切り替えます。

- **デバッグモード**をオン → 発動間隔と予告の単位が「分」ではなく「秒」になります
- **作業時間帯を無視**をオン → 時間帯の判定を飛ばして常に作業中とみなします

「一般」タブで 間隔 `60` / 休憩 `15` にすると、60秒ごとに15秒の休憩が来ます。
デバッグモード中は記録されません。確認が終わったら必ずオフに戻してください。
戻し忘れると、数十秒おきに画面を奪われます。

### 構成

```
Koshimonban/Sources/
  App/         エントリポイント、ライフサイクル
  Models/      設定・作業時間帯・記録などの型
  Scheduling/  発動判定、画面ロックとスリープの検知
  Overlay/     休憩中の全画面オーバーレイ、予告ウィンドウ
  Video/       YouTube / ローカル動画の再生とフォールバック
  Storage/     JSON の読み書き、パス解決、集計
  System/      LaunchAgent、多重起動の防止
  UI/          メニューバーと設定画面
  Resources/   アプリアイコン
```

`Koshimonban/Sources` は Xcode の buildable folder として登録してあります。
ファイルを増やしても `.xcodeproj` を編集する必要はありません。

`.xcodeproj` / `project.pbxproj` は手で編集しないでください。高確率で壊れます。
